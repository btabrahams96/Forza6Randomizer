# Surface brief: the app (Roll, Garage, Add Cars, Edit Car, Profiles)

Mode: Operate. The world was established by the approved mockups (`.superpowers/brainstorm/57430-1793203401/content/*.html`; Bryton: "love it"). We inherit it rather than inventing a new one.

## Direction contract

THESIS: A garage you roll from, not a database you browse. The roll is the hero; the garage is the fast iOS list behind it. We refuse the category default of a dashboard with car cards in a grid.

OWN-WORLD: iOS dark grouped-list material. True black ground, #1c1c1e/#2c2c2e grouped surfaces, hairline separators, SF system text. Color comes only from FH6 class badges (a solid class letter block joined to a black PI block) and one system blue for actions. Car photos sit on a soft dark radial floor.

STORY: Open, see the last pool and filters, tap Roll, get a car with its class and PI, go race. Later, tap a car and type the new PI from the game.

FIRST VIEWPORT: Roll tab. Large title "Roll", profile avatar top right. My Garage / All Cars segmented control. Chips that wrap. The result card takes about 55% of the height: hero photo on a radial floor, make · year, model at 24px bold, class badge and meta. "N matching cars". A full-width blue Roll button sits in the thumb zone above the tab bar.

FORM: Native iOS app screens (1 of 1: the user approved this form). seed: none (unavailable). Code-led build in an inherited world; no concept roll was run.

SIGNATURE: The roll reveal. The card drops in with a short spring from slight scale and blur as the photo resolves, and the class badge lands last. A second tap interrupts and rerolls.
